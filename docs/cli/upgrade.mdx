```text
aboard upgrade [--version V] [--json]
```

Downloads the latest release (or `--version`) for this system, checks it the way the install script does (the checksums' signature when cosign is installed, the archive's checksum and contents), replaces this aboard and the launchers next to it, then runs the new aboard's init `--yes` for the harnesses set up for every project, so the skill and hooks match the new build. Every check comes before anything is replaced.

It upgrades an aboard installed by the install script. For one installed with Homebrew or built from source it changes nothing and gives the command to run instead. It is a person's action, so it is refused inside an agent's session. Running daemons and the local server switch to the new aboard at the next command.

## Flags

| Flag | What it does |
| --- | --- |
| `--version V` | Install this version, such as 0.2.0, instead of the latest. |
| `--json` | Print one JSON object instead of text, errors included. |

## Examples

```bash
# Install the latest release
aboard upgrade

# Install a given release
aboard upgrade --version 0.2.0
```
