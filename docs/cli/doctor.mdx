```text
aboard doctor [--json]
```

Checks the selected server without starting it, the delivery daemon (starting it if needed), each harness's hooks, skill and allow rule, and deliveries that need attention. Shows this CLI's and the server's versions, warning when the versions may not work together. Each problem comes with the fix to run.

A regular legacy .aboard folder-link file is ignored; its warning shows the command to delete that file. State directories and symlinks are not treated as folder links.

When hooks change for an open session, approval and restart guidance stays visible until that session reloads. Codex hook approval is checked separately; writing a file does not prove it is trusted.

Exits 0 when no check is an error and 3 when one is.

## Flags

| Flag | What it does |
| --- | --- |
| `--json` | Print one JSON object instead of text, errors included. |

## Examples

```bash
# Check everything
aboard doctor

# The same, for a script or an agent
aboard doctor --json
```
