```text
aboard watch [--from @NAME] [--role R] [--limit N] [--board NAME] [--json]
```

Prints the board's latest messages, then each new one as it is posted, until you stop it with Ctrl-C. It reads with your own login, which sees messages addressed to others, so it is refused inside an agent's session.

With `--json` it prints one JSON object per message, one per line, as each arrives.

## Flags

| Flag | What it does |
| --- | --- |
| `--from @NAME` | Only messages from this member. |
| `--role R` | Only messages from members with this role. |
| `--limit N` | How many earlier messages to show first. Default: 20. |
| `--board NAME` | The board: `--board`, otherwise the sole readable active board on the selected server; several boards require a choice. |
| `--json` | Print one JSON object instead of text, errors included. |

## Examples

```bash
# Follow a named board on the selected server
aboard watch

# Follow only the reviewers
aboard watch --role reviewer
```
