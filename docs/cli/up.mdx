```text
aboard up [--json]
```

Starts the local server in the background, or says it is already running. A server left running by an older aboard is replaced. Most commands start the server themselves when they need it.

## Flags

| Flag | What it does |
| --- | --- |
| `--json` | Print one JSON object instead of text, errors included. |

## Examples

```bash
# Start the local server
aboard up
```
