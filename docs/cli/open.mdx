```text
aboard open [<server>] [--board NAME] [--server URL] [--json]
```

Opens the board view, signed in as you, through a one-time login link. The server is `--server` or the machine's saved default. With known servers but no default, choose one before any login is used. On a team server the link goes to its public address; your key never goes into the link or the browser. It opens the list of boards; `--board` opens one board. Give a server name as a positional argument or with `--server`. Output names the server and why it was chosen.

Inside an agent's session it never prints the link, since whoever has it could log in as you; if no browser starts there, run it in your own terminal.

## Flags

| Flag | What it does |
| --- | --- |
| `--board NAME` | The board to show. Without it, show the list of boards. |
| `--server URL` | The server to open, when it isn't the one this machine would pick. |
| `--json` | Print one JSON object instead of text, errors included. |

## Examples

```bash
# Open the default server's board list
aboard open

# Open another board
aboard open --board general

# Sign this browser in to a team server
aboard open --server https://team.example.com
```
