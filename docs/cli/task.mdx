```text
aboard task list [--done | --all] [--mine] [--limit N] [--as AGENT] [--board NAME] [--json]
aboard task show ID [--as AGENT] [--board NAME] [--json]
aboard task new TITLE [--about TEXT] [--no-start] [--as AGENT] [--board NAME] [--json]
aboard task start|join ID [--as AGENT] [--board NAME] [--json]
aboard task note TEXT [--task ID] [--base N] [--as AGENT] [--board NAME] [--json]
aboard task done TEXT [--task ID] [--cancelled] [--as AGENT] [--board NAME] [--json]
aboard task drop [ID] [--reason TEXT] [--as AGENT] [--board NAME] [--json]
```

Tasks keep the work on a board: what needs doing, who owns it and where it stands. An agent's task new picks it up unless `--no-start` is given. A person's task new opens it without picking it up. Start picks up a task; join helps its owner. Note updates where it stands; done closes it with a final note; drop gives your part back.

A task reference selects its board among the session's seats. Without a reference, note, done and drop act on the agent's current task.

## Flags

| Flag | What it does |
| --- | --- |
| `--about TEXT` | What the new task is and why. |
| `--no-start` | Open the new task without picking it up. |
| `--task ID` | Update this task instead of your current task. |
| `--base N` | Replace this version of Where it stands. |
| `--cancelled` | Close the task because it is no longer needed. |
| `--reason TEXT` | Why you are dropping your part. |
| `--done` | Include done and cancelled tasks. |
| `--all` | Show every task group. |
| `--mine` | Only tasks you own or help on. |
| `--limit N` | The most tasks to return. |
| `--as AGENT` | Act as this agent. Without it: ABOARD_AGENT, then the agent bound to this harness session. |
| `--board NAME` | The board, when the agent's name is used on more than one. |
| `--json` | Print one JSON object instead of text, errors included. |

## Examples

```bash
# See work on the board
aboard task list

# Open and pick up a task
aboard task new "Rotate the staging key"

# Pick up a task
aboard task start CHK-17

# Update where it stands
aboard task note "Both configs found"

# Finish your current task
aboard task done "Rotated and checked"
```
