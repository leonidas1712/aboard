```text
aboard version [--json]
```

Prints the version of this aboard. aboard `--version` is an alias. With `--json` it also gives the commit it was built from and that commit's time, for a build from a Git checkout.

## Flags

| Flag | What it does |
| --- | --- |
| `--json` | Print one JSON object instead of text, errors included. |

## Examples

```bash
# The version and commit
aboard version --json
```
